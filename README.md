## Overview

This repository holds the Simulacrum horizontal logo (symbol and SIMULACRUM wordmark) as three PNG files, 3451 pixels wide (761 or 762 high) with transparent backgrounds, at stable public URLs. `Asset 1@4x-8.png` is the dark blue version for light backgrounds, `Asset 2@4x-8.png` is the white version for dark backgrounds, and `Asset 3@4x-8.png` is the black version for single-colour use.

**Who it is for.** Anyone who needs the Simulacrum logo: partners, press, event organisers, and Simulacrum's own documents and READMEs that link the image by URL.

**What it does not do.** It holds no code, no vector (SVG) logo, and no brand guidelines, colour tokens or typefaces. It grants no right to use the Simulacrum name or marks; see License and contact.

## Quickstart

<!-- smlcrm:tested 2026-10-05 macOS 26.6.2, curl 8.7.1 -->
You need `curl`. No account is needed: the repository is public.

```bash
curl -sSfLo smlcrm-logo-blue.png \
  "https://raw.githubusercontent.com/Smlcrm/smlcrm-brand-assets/main/Asset%201%404x-8.png"
```

Check the file you downloaded:

```bash
file smlcrm-logo-blue.png
```

Expected output:

```text
smlcrm-logo-blue.png: PNG image data, 3451 x 762, 8-bit colormap, non-interlaced
```
